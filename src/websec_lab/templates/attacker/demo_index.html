分屏演示模式

把“看不见的攻击”变成看得见的故事：左侧是受害者看到的诱导页面，右侧实时显示 victim 服务器上受害者账户的真实状态。每一次诱导点击之后发生了什么，由时间线 解说自动给出，不需要在两个标签页之间来回切换和脑补。

开始经典演示（透明覆盖） 光标劫持演示（cursorjacking）

另有一个不进七类场景的补充演示：光标劫持（cursorjacking）—— 隐藏真实光标、用假光标制造位移，让你点在诱饵上、实际点到另一个按钮。 它不需要 iframe，所以 XFO / CSP 这类框架控制对它无效。

演示前三步准备

  1. 点演示页右上角「本页登录 victim（alice）」，用 alice / alice-lab 登录后会自动跳回演示页；
  2. 回到本页点击“开始经典演示”；
  3. 在左侧点“立即领取试用装”，然后什么都不用做——看右侧。

看什么

点击瞬间，右侧会出现四条时间线：点击落入透明 iframe → victim 表单被提交 → 交易记录新增 → 余额下降。攻击成功的判定不靠肉眼，而靠 victim 状态 API 的前后 对比，与自动化审计（M7）使用同一证据源。右上角“透视”开关可以把透明 iframe 显示出来，向观众展示按钮下方的真实页面。
