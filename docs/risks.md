# 风险登记表（T0010）

记录可能影响实验复现与结论稳定性的环境/技术风险及应对状态。

| 编号 | 风险 | 影响 | 状态与缓解 |
|---|---|---|---|
| R01 | 浏览器版本差异（XFO/CSP/sandbox/SameSite 行为随版本演进） | 攻防结论随浏览器升级漂移 | 历史HTTP实验见各自版本记录；2026-11-04 HTTPS使用Chrome156.0.8078.80与Edge156.0.4314.58，逐例记录通道及CDP版本，不外推到Firefox |
| R02 | Playwright 官方浏览器运行时下载源 DNS 不通 | 无法使用 Playwright 自带浏览器 | 已缓解：浏览器发现模块自动使用本机 Chrome/Edge（`doctor` 可查），全部烟雾与实验走该路径 |
| R03 | ffmpeg 二进制不可用 | 动态审计无法录制视频 | 已缓解：trace 与网络日志不依赖 ffmpeg；视频录制留作可选项并在文档标注 |
| R04 | Docker / mkcert未安装 | 预定多域HTTPS方案无法直接执行 | 已解决本机部署：原生Nginx+OpenSSL、五域SAN、当前用户CA信任，五域与两浏览器TLS检查通过。Docker编排另列待办 |
| R05 | 127.0.0.1端口区分使victim/attacker同站 | HTTP端口实验无法证明SameSite跨站效果 | 已解决该实验缺口：.test多域HTTPS及同站子域对照，两浏览器各3次共96例全部通过，Cookie、业务状态与顶层GET导航均已复核。证据见docs/https-progress-2026-11-04.md；通用审计CLI的HTTPS接入另列任务 |
| R06 | 端口冲突（5100–5400 被占用） | 服务启动失败 | 一键脚本启动前做健康检查；烟雾与实验全部使用临时端口绑定，不依赖固定端口 |
| R07 | 跨域调试信息受限（contentDocument 为 null） | 页内 JS 无法独立判定嵌入是否被拒 | 已解决：多信号判定（控制台 Refused/CSP 消息 + load 计数 + 超时兜底），M6/M7 双侧落地并验证 |
| R08 | 透明对齐依赖目标页面"按钮居中"契约 | victim 模板改动可能破坏攻击对齐 | 契约已写入模板注释并有 16 项测试与真实浏览器烟雾保护；改版验证过两次（视觉升级前后） |
| R09 | Windows 控制台编码差异（中文输出） | 脚本输出乱码影响演示 | 脚本输出以英文标签为主、中文仅页面/文档层；PowerShell 7 验证通过 |
| R10 | 仓库尚无 Git 提交 | 成果无版本快照，回溯困难 | 待办：首次提交 + 里程碑标签（见版本清单 docs/version-manifest.md） |
