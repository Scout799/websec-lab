# 威胁模型与实验边界

## 受保护资产

- 用户已认证会话；
- 模拟账户资料；
- 模拟余额和交易状态；
- 模拟授权状态；
- 用户对界面内容与点击对象的正确认知。

## 攻击者能力

最终实验加入`same.victim.test`同站不同源别名和受控双窗口连续点击。浏览器驱动读取框架仅用于证据收集，核心攻击使用页面坐标输入；窗口试验使用两次浏览器协议输入，不等于任意操作系统全局硬件双击。双通道只根据页面/CSP信号分析，不读取业务成功标签，合法嵌入支付也作为正常对照保留。

实验中的攻击者：

- 能控制 `attacker.test` 的 HTML、CSS 和 JavaScript；
- 能诱导实验账户访问攻击页面；
- 能尝试在 iframe 或独立窗口中加载目标页面；
- 能控制遮罩层、透明度、裁剪区域和点击诱导流程；
- 不能读取受同源策略保护的目标页面 DOM；
- 不能控制受害网站、浏览器或操作系统；
- 不拥有用户密码和服务器密钥。

## 信任边界

| 区域 | 信任级别 | 说明 |
|---|---|---|
| `victim.test` | 受信业务域 | 存放模拟敏感操作 |
| `partner.test` | 条件受信域 | 只允许约定的嵌入场景 |
| `attacker.test` | 不受信域 | 用于本地攻击实验 |
| `audit.test` | 测试控制域 | 运行审计和实验调度 |

## 核心安全性质

1. 未授权来源不能把敏感页面用于可交互的 framing；
2. 合法合作方只获得明确授权的嵌入能力；
3. 高风险操作需要服务器可验证的用户确认；
4. 静态策略预测应与浏览器实际行为一致；
5. 实验结果应能由保存的配置和版本信息复现。

## 非目标

- 不测试真实网站；
- 不绕过验证码、MFA 或真实支付系统；
- 不实施凭证窃取、会话窃取或恶意软件投递；
- 不将实验代码用于未授权环境；
- 当前阶段不研究浏览器内核漏洞。

## 数据与伦理边界

- 使用固定的虚构账号和模拟金额；
- 不采集真实用户行为；
- 不执行未经审批的用户研究；
- 自动化点击只作用于本地测试页面；
- 报告中的截图不得包含个人数据或本机敏感信息。
