## 5. 验证边界

- 本轮未扩展 Double Clickjacking、双通道攻击后审计或多域 HTTPS。
- `static` 保留用户请求祖先链的结果；`probe_static` 和一致性只对应实际单层 probe 来源。若两者不同，不能称已动态验证用户请求的全部祖先链。
- 没有浏览器文档响应时，静态结果是参考值，`agree=null`；动态失败时总体 `inconclusive`。
- Firefox 未在本轮实测；Chrome/Edge 的专项回归不代表所有 profile/攻击组合均已覆盖。
- 原 `artifacts/experiments/final-run` 为历史数据，本轮未覆盖或重新执行那套 M9 矩阵。正式统计应在本轮修复后重新采集。
- 原仓库已有改动保留，本轮未创建 Git 提交或发布标签。
