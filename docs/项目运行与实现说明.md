# 点击劫持的分析与防御

## 1. 启动

在 Windows 上解压完整项目，在包含 `pyproject.toml`、`requirements.lock` 和 `config/` 的目录打开 PowerShell。新电脑先创建 `Websec` 环境并安装项目。已有 `Websec` 环境时跳过第一行。

```powershell
conda create -n Websec python=3.12 pip -y
conda run -n Websec python -m pip install -r requirements.lock
conda run -n Websec python -m pip install --no-deps --no-build-isolation -e .
conda run -n Websec python -m websec_lab --help
```

`websec-lab` 是安装项目后生成的命令。下面使用等价的 `python -m websec_lab` 入口，由 Conda 选择 Python 环境。若 PowerShell 找不到 `conda`，从开始菜单打开 Anaconda PowerShell Prompt。

首次启动先执行 `conda run -n Websec python -m websec_lab db upgrade`，初始化数据库和测试账户。然后启动银行服务：

```powershell
$env:WEBSEC_DEFENSE_PROFILE = 'xfo-deny'
conda run --no-capture-output -n Websec python -m websec_lab run victim
```

若 `http://127.0.0.1:5100/healthz` 已返回 `status: ok`，直接进入下一节。服务运行时保留终端，结束后在该终端按 `Ctrl+C`。

## 2. 运行

1. 用普通浏览器打开 `http://127.0.0.1:5100/login`，以测试账号 `alice`、密码 `alice-lab` 登录。
2. 在银行页面查看余额、模拟转账、交易记录、应用授权和审计日志。
3. 在另一个终端运行静态审计，查看银行登录页当前的响应头和 Cookie 配置。分屏演示和动态结果可打开 [交互录屏](../artifacts/demo-video/project_demo.webm)、[合并审计样例](../artifacts/demo-video/audit_report_sample.html) 和 [CSP 阻断报告](../artifacts/finalization/rehearsals/round-1-csp-none.html)。

```powershell
conda run --no-capture-output -n Websec python -m websec_lab analyze http://127.0.0.1:5100/login
```

## 3. 功能

- **模拟银行与分屏演示**。分屏展示操作界面、账户余额、交易和事件时间线。通过转账、授权或余额变化核对模拟业务结果。
- **防御与合法嵌入**。可配置 XFO、CSP、SameSite 和业务确认，比较来源受限时的浏览器表现与合法合作方组件的可用性。
- **静态和动态审计**。解析响应头，用真实浏览器记录嵌入结果、控制台信息和截图，生成 JSON、Markdown 和 HTML 报告。
